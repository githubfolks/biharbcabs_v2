
1. Bookings:
1.1. There are 3 types of bookings; 1. Outstation, 2. Local(Airport, Railway Station) 3. Rental. User will select one of these plans.
1.2. These are the cab types: MICRO, MINI, SEDAN, PRIME SEDAN, SUV, LUX, Bike. There will be per day charge of the cabs (say PDCRG) and Extra charge for per hour (say PHEXCHG)
1.3. These cabs will be separated by fuel types; Petrol, CNG, Diesel (say FT). Cab will have its milage to be set by the admin (say CML).
1.4. Fuel price table will maintain the current price of Petrol, CNG, Diesel (say FP)
1.5. Admin will configure Commission Percentage (say ACP).
1.6. Admin will configure GST (Say GST)
1.7. CRM admin will create packages with cab types using below values:
Name: Package name
KM: Total KM for the plan
Hours: Total Travel Time
Plan Cost:
	Total Fair = (PDCRG/12)*Hours
	GST Charge = (Total Fair)*GST/100
	Total Payment = Total Fair + GST Charge
1.8. Once the cab gets booked; WA workflow will execute as it is available.
1.9. On final billing/payment the Total Payment will be recalculated as per PHEXCHG.
1.10. Admin Commission = (Total Fair)*ACP/100 will be deducted from the cab driver's subscription/comission plans.
